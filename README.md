# Student Management System (Java)

## About the Project
Student Management System is a menu-driven Java console application that allows users to manage student records using arrays and methods.

## Features
- Add Student
- Display All Students
- Search Student by ID
- Update Student Details
- Prevent Duplicate Student IDs
- Exit the Application

## Technologies Used
- Java
- Scanner Class
- IntelliJ IDEA
- JDK 23

## Java Concepts Used
- Arrays
- Methods
- Loops
- Conditional Statements
- Switch Case
- Boolean
- User Input using Scanner

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open `Main.java`.
4. Run the Main class.
5. Select an option from the menu.

## Application Menu

1. Add Student
2. Display Student
3. Search Student
4. Update Student
5. Exit

## Storage
Student records are stored in arrays during program execution. The application currently supports a maximum of 5 students. Data is not permanently stored after the program closes.
